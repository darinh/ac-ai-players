# Archetype definitions

This directory will hold one YAML file per archetype once the loader exists
(planned for M4 — see [`../roadmap/milestones.md`](../roadmap/milestones.md)).

For now, archetypes are described prose-style in
[`../docs/archetypes.md`](../docs/archetypes.md). The YAML stubs in this
directory are illustrative — schema is not locked, field names will change.

## Adding a new archetype

1. Open an "Archetype proposal" issue using the template.
2. Once accepted, add a YAML file here named `<id>.yaml`.
3. Add a row to the table in `docs/archetypes.md`.
4. Add the archetype id to the relevant zone spawn tables (TBD).

See [`../CONTRIBUTING.md`](../CONTRIBUTING.md) for the full process.

## Schema (draft, not locked)

See the example block in `docs/archetypes.md`. The starter YAML files in
this directory show the same shape.
