# reference

This folder holds committed reference outputs from
`WorldNavBuilder` for visual inspection. The sibling `data/`
folder is gitignored and holds regeneratable runtime output.

- `academy-8602.svg` — top-down view of the indoor cell graph in
  the academy landblock (`0x8602`). Generated by:
  ```pwsh
  dotnet run --project experiments/world-nav/src/WorldNavBuilder \
      -c Release \
      -- --dat C:\ACE\Dats --landblock 8602 --out experiments/world-nav/reference/academy-8602.svg
  ```
  568 cells, 1620 portals. Each cell is a blue rectangle, dark blue
  dot at its centroid; green dots mark portal polygon centroids;
  grey lines connect cell-centroid through portal-centroid to the
  neighbouring cell-centroid (the indoor navmesh edges).
