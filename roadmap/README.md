# Roadmap

Planning artifacts. Read these in order:

1. [`milestones.md`](milestones.md) — the sequence from "nothing" to
   "populated server", with success criteria per milestone.
2. [`open-questions.md`](open-questions.md) — things we haven't
   decided yet, grouped by area. These either become research issues,
   ADRs, or get explicitly deferred.

For the broader design context that the roadmap is delivering against,
see [`../docs/architecture.md`](../docs/architecture.md).
